# WavePulse 无线设备电量助手 v0.1 · .NET Framework 4.8 默认版

这是 WavePulse 当前唯一维护和发布的版本，不内置 .NET 运行环境。

## 运行要求

- Windows 11 x64。
- Microsoft .NET Framework 4.8 或更高版本。
- Windows 11 通常已经包含兼容的 .NET Framework；若系统提示缺少运行环境，请安装微软官方 .NET Framework 4.8 Runtime 后重新启动程序。
- 微软官方下载页：https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/net48

## 使用方法

双击 `WavePulse 无线设备电量助手.exe` 即可运行。环境检测器与主程序已经封装成一个 EXE；原生入口会先检查运行环境，再启动内置应用。

发布、复制或分享时只需保留 `WavePulse 无线设备电量助手.exe`。首次运行会在 EXE 同目录自动建立隐藏运行缓存；缺少环境时，提示窗口提供微软官方下载链接，安装完成后点击“重新检测”即可继续。应用设置中的“运行环境检测 → 查看提示”可以随时预览这套提示样式。

程序会在当前目录的 `data` 文件夹保存设备名称、类型、图标、浮窗、刷新周期和颜色等配置；目录不可写时会改存到当前用户的本地应用数据目录。

内置主程序带有 SHA-256 完整性校验，本地设置带有完整性签名。若检测到外部修改，应用会阻止加载并保留备份。该防护用于阻止常见拆包替换与直接修改，不能承诺本地客户端绝对不可逆向。

程序使用单实例运行，同一时间只会启动一个 WavePulse 主程序。版权所有人：yuban。

## 从源码构建

在项目根目录运行：

```powershell
.\build.ps1
```

构建过程使用微软官方的 .NET Framework 4.8 参考程序集、Windows SDK 契约包，以及本地 TinyCC 工具生成原生启动器；编译工具不会打进最终发布包。`build-net48.ps1` 是同一构建的兼容入口。
