# 使用说明

## 开始使用

从 [Releases](https://github.com/zhuhan0204/Windows-WavePulse/releases) 下载 EXE 或 ZIP。ZIP 先解压，建议放到固定且可写的文件夹，避免在临时目录中开启开机自启。

支持 Windows 11 x64，需要 .NET Framework 4.8 或兼容的更高版本，无需 .NET 8。缺少环境时，启动器提供微软下载链接，安装后点击“重新检测”；点击“关闭”则退出启动器。

首次运行没有个人设备预设。蓝牙设备需先配对；2.4G 设备需连接对应接收器并唤醒。

## 设备列表

- 顶部切换蓝牙与 2.4G 设备，数量显示在中文括号中。
- 已连接设备排在前面；可在设置中开启“仅显示已连接设备”。
- 右下角图标为隐藏设备管理、设置与刷新列表，悬停可查看说明。
- 电量旁的刷新图标只刷新该设备；“刷新列表”重新枚举设备。
- 点击设备行空白处展开 / 收起“设备信息”和“悬浮窗信息”，不会影响行内控件。
- “未上报”不等于“未连接”。只有受支持接口返回电量时才展示百分比；离线不继续显示旧百分比。

## 设备信息

名称最多 20 个字符，输入框显示计数。类型可选自动识别、鼠标、键盘、耳机、手柄或其他。

悬停图标可上传图片，已有自定义图标时可恢复内置图标。更改类型不会覆盖上传的图标。支持 PNG、JPG/JPEG、ICO 和 BMP，建议正方形透明 PNG、128×128 或更大，不超过 5 MB。

自动刷新单独设置，可关闭，或选择 10 分钟、30 分钟、1 小时、3 小时、5 小时。列表与浮窗中的时间表示最近读取时间，不代表设备刚刚测量了电池。

## 悬浮窗信息

- 开启“显示悬浮窗”，多屏时选择目标屏幕。
- 尺寸选小、中、大，或自定义宽高：160–420 × 56–160，保存后生效。
- 透明度为 1–100%，滑杆拖动实时生效。
- 逐设备设置低电量阈值，以及底色、低电量色、离线颜色；可恢复默认。
- “离线保留浮窗”保留窗口，不保留旧电量显示。

右键菜单依次为手动刷新、固定位置、置顶、透明度与关闭浮窗。固定后不能拖动；快捷透明度为 100%、75%、50%、25%。

## 合并展示

在设置中打开合并展示，展开设备选择区，勾选设备并拖动手柄排序。蓝牙与 2.4G 在同一列表中，通过标签区分。

隐藏设备不出现在候选列表中。合并窗按已选设备中的最大尺寸适配，不改变独立浮窗设置，也可单独固定、置顶及调整透明度。

## 隐藏与移除

隐藏设备会关闭对应独立浮窗，并从列表及合并展示中排除；通过右下角隐藏设备入口按连接方式查看和恢复。

删除记录不是卸载系统设备或永久屏蔽。记录从应用移除并关闭对应浮窗，重新“刷新列表”后仍可能发现。

## 多显示器

记录显示器身份和屏内相对位置，以适应分辨率、缩放比例与负坐标布局。目标屏幕在开机时缺失或使用中断开时暂停显示，保留目标和开关；重连稳定约 2 秒后恢复，不等待电量刷新周期。

不同显卡、扩展坞与混合 DPI 仍需实机验证。更换接口后若系统分配新身份，需重新选择屏幕；旧版记录缺少身份信息时也建议重新选择一次。

## 数据保存与日志

优先在 EXE 同目录的 `data/` 保存偏好与最近 24 小时日志。目录不可写时，改存到当前用户本地应用数据目录下 `BluetoothBatteryMonitor/`。

首次运行创建隐藏的 `.wavepulse-runtime/` 缓存。无需携带整个缓存分发程序。迁移个人设置时可携带自己的 `data/`，但**公开发布不得混入个人 data 或日志**。

设置中的导出日志只包含最近 24 小时。日志可能包含名称、蓝牙地址、USB 标识、序列信息与本机路径。请先脱敏，再提供相关片段，不要直接上传公开仓库或 Issue。

## 后台与退出

主窗口关闭只隐藏到托盘。左键托盘图标重新打开，右键菜单彻底退出。

开机自启按当前 EXE 路径后台启动，立即刷新一次。移动 EXE 后，应重新关闭 / 开启自启以更新路径。

## 常见问题

**已连接但没有电量？** 可能没有标准接口、设备休眠、驱动未公开数值或型号未适配。先唤醒后刷新，不要把“未上报”当成 0%。

**耳机没有左右标识？** 没有可靠属性时不按电量高低猜耳别。部分 HFP 设备轮换上报一个数值，两个样本可能不是同时取得。

**为什么只显示“充电中”？** 部分 2.4G 设备充电时百分比不可靠，优先展示状态，避免错误的精确数值。

**支持所有 2.4G 产品吗？** 不支持。同品牌的不同型号、固件或接收器也可能不同，请查看应用内适配目录。
