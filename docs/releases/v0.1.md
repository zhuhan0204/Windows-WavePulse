# WavePulse v0.1 · 首个公开版本

WavePulse 无线设备电量助手首次公开发布：在 Windows 11 集中查看蓝牙与部分已适配 2.4G 设备电量，用独立或合并浮窗留在桌面上。

## 首版内容

- 蓝牙 / 2.4G 双列表、连接状态排序、最近刷新时间与逐设备刷新周期。
- 罗技 M750、Compx 部分接收器、迈从 G98 V2、前行者 S9 Pro 的适配逻辑与检索目录。
- 名称、类型、图标、隐藏 / 恢复与本地偏好保存。
- 圆环电量、低电量阈值、独立配色、实时透明度与尺寸。
- 单独 / 合并浮窗、排序、固定、置顶、离线保留与右键刷新。
- 目标屏幕定位，断开隐藏并保留位置，重连后恢复。
- 托盘、开机后台运行、启动后立即刷新及最近 24 小时日志。
- .NET Framework 4.8 单 EXE，启动前检查环境，不内置 .NET，也不需要 .NET 8。

## 下载

- 直接运行：`WavePulse-v0.1-win-x64.exe`。
- 压缩包：`WavePulse-v0.1-win-x64.zip`，先解压再运行，附使用说明。
- 校验：`SHA256SUMS.txt`，核对附件 SHA-256。
- 源码：Git 标签 `v0.1` 对应的源代码归档。

需要 Windows 11 x64 与 .NET Framework 4.8 或兼容的更高版本。[微软环境下载页](https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/net48)

关闭主窗口只隐藏到托盘，彻底退出请使用托盘菜单。公开包没有个人配置、日志或个人耳机地址的专属映射。

## 已知限制

并非所有无线设备都能读取电量，2.4G 按型号适配；部分设备充电时数值不准确，必要时显示“充电中”。无可靠左右属性的耳机不按电量高低猜测耳别，轮换样本可能不是同时取得。

多屏逻辑经过模拟验证，不同显卡、扩展坞与混合 DPI 的真实插拔仍需实测。

完整记录见 [CHANGELOG](https://github.com/zhuhan0204/Windows-WavePulse/blob/v0.1/CHANGELOG.md)。反馈请附版本、连接方式、型号和脱敏截图，不要公开上传完整原始日志。
